# Kubik words

The design skill `kubik` carries one file about the words on a piece, and that file is the whole
of this skill: `../kubik/words.md`, beside this directory in the same package. Read it, all four
sections, before writing or rewriting anything, and run its last section over the result.

What it holds: whom the text serves and what that cuts (§1), the habits that give a machine away,
in English and in Russian (§2), what a person's own voice keeps (§3), and the pass before the text
is handed over (§4).

Two things it asks you to say in your own note: which habits you found and removed, in a line;
and, when the text was somebody's own, what changed in substance, so they can check that nothing
was added or lost.
